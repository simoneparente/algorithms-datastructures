# Algorithms and Data Structures 🌳

This repository contains my personal study notes, algorithmic tracings, and structural analysis for the Algorithms and Data Structures exam (Computer Science, Università degli Studi di Napoli Federico II).

The goal of this project is to document the theoretical concepts and practical executions of complex algorithms, focusing on correct asymptotic analysis, memory management, and advanced data structure invariants. Basic data structures (Arrays, Linked Lists, simple BSTs) are intentionally omitted.

## 📝 Methodology

All notes are handwritten and logically structured to break down complex recursive algorithms into step-by-step visual executions.

When pseudo-code is provided alongside the theoretical notes, it emphasizes:

- Clear variable naming.
- Clean logic and correct pointer assignments.
- Edge case management.
